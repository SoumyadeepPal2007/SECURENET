SECURENET
Security Validation for AI-Generated Code

Problem Statement

The challenge is to build a tool capable of scanning AI-generated code, identifying security vulnerabilities, and providing secure remediation recommendations before deployment and should support automated scanning inside CI/CD pipelines and provide clear, actionable security insights through a centralized dashboard or reporting system.

Exact Deliverables

Teams are expected to deliver: ● Code Security Scanner for identifying common vulnerabilities in AI-generated code. ● CI/CD Integration Plugin for GitHub Actions, GitLab CI, or Jenkins. ● Vulnerability Detection Engine supporting common web application security issues. ● Remediation Module for suggesting secure code fixes. ● Support for at least one major programming language Relevance I-generated code is rapidly becoming part of modern software development workflows across startups, enterprises, and cloud-native environments. However, insecure AI-generated code can introduce vulnerabilities into web applications, APIs, and cloud services if proper security validation is not performed. As India’s software ecosystem rapidly adopts AI-assisted development tools, there is increasing need for affordable and scalable security solutions that can help developers identify vulnerabilities early and improve secure coding practices. Dataset(s) / Benchmarks Students may use: CWE Top 25, OWASP Benchmark Project, SATE IV Juliet Test Suite, MultiAIGCD, AIGCodeSet, KodCode, The Stack, CodeMix, FormAI, Vulnerable open-source code repositories

Milestones

Phase 1 - Research & Architecture Design ● Design architecture for code scanning and reporting. ● Set up CI/CD testing environment. Phase 2 - Vulnerability Detection Development ● Build automated vulnerability scanning engine. ● Implement detection for common web application security flaws. ● Add basic severity classification. Phase 3 - Remediation & CI/CD Integration ● Build remediation suggestion module. ● Generate security reports and developer alerts. Phase 4 - Testing & Optimization ● Test against vulnerable code samples. ● Benchmark detection accuracy and false positives.
